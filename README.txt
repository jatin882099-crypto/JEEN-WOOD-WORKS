URBAN WOOD WORKS WEBSITE

IMPORTANT: Before publishing, open index.html and find the section:
EDIT YOUR BUSINESS DETAILS HERE

Change these values:
- name = business name
- location = area/city
- timings = opening hours
- phone = phone number shown on the site
- whatsapp = WhatsApp number with country code, without + or spaces

Example:
location: "Rohini, Delhi"
timings: "10:00 AM – 8:00 PM"
phone: "+91 98765 43210"
whatsapp: "919876543210"

After saving index.html, upload/commit it to GitHub Pages. The live site will update automatically.
